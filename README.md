# Seedflow Website

A modern website for Seedflow, an accounting platform that helps growing businesses manage their finances.

## About Seedflow

Seedflow helps businesses keep their finances organized and their growth moving forward.

### ✨ Core Features

- **Invoice Management** - Create, send, and track invoices
- **Expense Tracking** - Keep business expenses organized
- **Financial Reports** - Understand business performance
- **Journal Entries** - Maintain accurate financial records

### 🚀 Key Features

- Modern, responsive design
- Seedflow brand experience
- SEO-optimized structure
- Fast performance
- Product-focused messaging

### 🛠️ Built With

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- Modern web standards

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
